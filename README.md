# Front-end Practice: Marketplace UI Pages

This repository contains static front-end recreation exercises inspired by Alibaba.com page layouts, including:

- AI Mode interface — `html/AI.html`
- Tax compliance information page — `html/tax.html`
- Help-center page — `html/help.html`

These are educational practice pages only. They are not official Alibaba.com pages, are not affiliated with Alibaba Group, and must not be used to impersonate Alibaba or collect user information.

## Run locally

Open the HTML files in a browser. The pages use local CSS and downloaded image assets, plus some externally hosted resources. Keep the existing folder structure so relative image and stylesheet paths continue to work.

## Current limitations

- Many navigation links are placeholders.
- The pages are static recreations, not connected to Alibaba services or accounts.
- External media and assets may change or become unavailable.
- Accessibility, responsive behavior, and browser compatibility need further testing.

## Portfolio note

Treat this as a front-end learning exercise, not a client project or original marketplace product. For a professional portfolio, prioritize original interfaces and clearly working features.
